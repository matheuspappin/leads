Configure sua Google Places API Key

O que é a Google Places API Key?

É uma chave pessoal que você obtém no Google Cloud Console. Com ela, você faz suas próprias buscas de leads sem depender de ninguém.

Como obter sua API Key

  1. Acesse console.cloud.google.com
  2. Crie ou selecione um projeto
  3. Vá em APIs e Serviços → Credenciais
  4. Clique em Criar Credenciais → Chave de API
  5. Ative a Places API (New) no seu projeto
  6. Cole a chave aqui acima e salve

Manual do Lead Hunter

Como funciona o sistema e o Score de Oportunidade

🎯 1. O que é o "Score de Oportunidade"?

O Score de Oportunidade é uma nota de 0 a 100. Quanto MAIOR for o score, MAIS FÁCIL é vender serviços para essa empresa.

  • Falta de Site (+40): Oportunidade para venda de website.
  • Nota Baixa (+25): Precisa de gestão de reputação online (abaixo de 4.0).
  • Sem Telefone (+15): Perfil incompleto.
  • Poucas Avaliações (+20): Menos de 10 avaliações, potencial para crescimento.
  • Avaliações Moderadas (+10): Entre 10 e 49 avaliações.
  • Sem Nenhuma Avaliação (+10): Nota cravada em "0".

⚙️ 2. Funcionalidades do Site

  • Privacidade de Chave: Cada usuário usa sua própria Google Places API Key (na aba Config).
  • Busca Inteligente e Cache: O sistema pesquisa até 60 empresas por busca. Resultados ficam em cache por 7 dias para economizar sua API Key.
  • Exportação de Dados: É possível baixar os resultados para CSV, contendo todos os dados e links para o Google Maps.
  • Histórico: Suas buscas ficam salvas e você pode apagá-las quando quiser.
